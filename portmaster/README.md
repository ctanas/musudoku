## Notes

Thanks to [amiralul](https://github.com/ctanas/musudoku) for creating muSudoku, a Sudoku game whose puzzles are generated on the device and graded by the techniques a person needs to solve them.

Puzzle packs (text files of puzzles) go in `ports/musudoku/packs/`. A starter pack is included.

## Controls

| Button | Action |
|--|--|
| D-pad / Left stick | Move |
| A | Open the number pad, place a number |
| B | Erase, close |
| X | Switch pen and pencil |
| Y | Hint (turn on in Settings) |
| L1 | Undo |
| R1 | Redo |
| Select | Fill or clear all notes |
| Start | Pause menu |
